# Funniest Autocorrect Fail

Entry for the make.fun bounty `u-zeroxfive-funniest-autocorrect-fail-ddf82154`.

The program writes a single line — a funny autocorrect fail — to
`/output/entry.txt`:

> I haven't had my coffin yet, don't talk to me.

(Intended: "coffee". Autocorrect sent "coffin".)

Run: `node main.ts` with `MAKEFUN_OUTPUT_DIR` set to the output directory.
